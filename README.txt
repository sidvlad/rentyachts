=====================================
   ON THE SEA - Yacht Charter
   Локальный запуск проекта
=====================================

ТРЕБОВАНИЯ:
- Node.js (https://nodejs.org) ИЛИ Python

ЗАПУСК:

Windows:
  1. Дважды кликните на файл start.bat
  2. Откроется браузер по адресу http://localhost:8080

Mac/Linux:
  1. Откройте терминал в папке проекта
  2. Выполните: ./start.sh
  3. Откроется браузер по адресу http://localhost:8080

Или через npm (если установлен Node.js):
  1. Откройте терминал в папке проекта
  2. Выполните: npm start

АДРЕСА:
- Главная страница: http://localhost:8080
- Админ-панель:     http://localhost:8080/admin/

АДМИН-ПАНЕЛЬ:
Для публикации изменений на сайт настройте GitHub Token
в разделе "Настройки" админ-панели.

Остановка сервера: нажмите Ctrl+C в терминале
