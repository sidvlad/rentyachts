=====================================
   ON THE SEA - Yacht Charter
   Локальный запуск проекта
=====================================

ЗАПУСК НА MAC:
  1. Дважды кликните на файл START-SERVER.command
  2. Разрешите запуск в настройках безопасности (если спросит)
  3. Браузер откроется автоматически

ЗАПУСК НА WINDOWS:
  1. Дважды кликните на файл start.bat
  2. Браузер откроется автоматически

АДРЕСА:
- Главная страница: http://localhost:8080
- Админ-панель:     http://localhost:8080/admin/

АДМИН-ПАНЕЛЬ:
В админке можно редактировать яхты, услуги и тексты.
Для публикации изменений настройте GitHub Token
в разделе "Настройки".

ОСТАНОВКА СЕРВЕРА:
Закройте окно терминала или нажмите Ctrl+C

ЕСЛИ НЕ ЗАПУСКАЕТСЯ (Mac):
Откройте Терминал и выполните:
  xcode-select --install
